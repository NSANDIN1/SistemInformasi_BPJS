Modul Kearsipan membutuhkan server PHP

GitHub Pages hanya melayani file statis, sehingga kearsipan.php beserta database SQLite tidak dapat dijalankan di sini.

Untuk menjalankan modul ini, gunakan hosting yang mendukung PHP, atau jalankan secara lokal dengan perintah php -S localhost:8000 di folder website, lalu buka http://localhost:8000.
